## Featured projects

### Advanced SQL Data Warehouse and Business Analytics

Built a retail data warehouse with **Bronze, Silver, and Gold layers**, a star schema, one fact table, and four dimension tables. Wrote **15+ SQL queries** using CTEs, window functions, views, and stored procedures, and used indexing to improve joins and year-over-year analysis.

### Superstore Retail Analytics and Automated Reporting

Created an end-to-end Python pipeline for retail sales, profitability, and customer analysis. The project covers data cleaning, feature engineering, seasonality, geospatial analysis, RFM customer segmentation, and Parquet export.

### [Salla Call Center Performance Dashboard](https://github.com/mostafa-elsawahly/salla-call-center-performance/blob/main/salla%20call%20center%20performance.pbix)

Built an interactive Power BI dashboard tracking **2 million calls**, **90% efficiency**, and a **91% service level**, with DAX measures and data modeling.

### [Electronics Retail Executive Dashboard](https://app.powerbi.com/groups/me/reports/76766fb0-2345-44e8-b2ab-418a742303d2/e6b9938127e5b4334a48?ctid=023e70ba-1df5-4718-905c-ad83100c01bc&experience=power-bi)

Modeled electronics sales data with a star schema and built DAX measures for AOV, ARPC, and returns. The analysis surfaced a **17% return rate** and high-value customer segments.

### [Dynamic Data Dashboard](https://github.com/mostafa-elsawahly/Dynamic-Dashboard)

Transforms CSV and Excel files into KPIs, trend and distribution views, and AI-assisted insights, with automated parsing and data-type detection.

### Workflow Automation — Digitera

Designed a no-code workflow using Zapier and applied the SCQA framework to organize the problem, process, and proposed solution.
