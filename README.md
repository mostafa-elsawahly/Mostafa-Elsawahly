## Selected projects

### [Salla Call Center Performance Dashboard](https://github.com/mostafa-elsawahly/salla-call-center-performance/blob/main/salla%20call%20center%20performance.pbix)
**Power BI · DAX · Data Modeling**

An interactive dashboard analyzing **2 million calls**, with views for monthly performance, agent results, call volume, and abandonment trends. The tracked KPIs include **90% efficiency**, **91% service level**, and **1% abandonment**.

### [Electronics Retail Executive Dashboard](https://app.powerbi.com/groups/me/reports/76766fb0-2345-44e8-b2ab-418a742303d2/e6b9938127e5b4334a48?ctid=023e70ba-1df5-4718-905c-ad83100c01bc&experience=power-bi)
**Power BI · Power Query · DAX · Star Schema**

Built an end-to-end sales and customer analysis dashboard. Modeled the data with a star schema, created measures for AOV, ARPC, and returns, and surfaced a **17% return rate** alongside high-value customer segments.

### [Dynamic Data Analysis Dashboard](https://github.com/mostafa-elsawahly/Dynamic-Dashboard)
**Excel · CSV · Data Visualization · AI-assisted insights**

Created a dashboard that parses datasets, detects data types, and presents KPIs, trends, and distributions, with a searchable view of the underlying data.
